🚀 QUICK START (3 Simple Steps)
================================

Step 1: Open Command Prompt
----------------------------
Press Win + R, type "cmd", press Enter

Step 2: Navigate to Project
----------------------------
Copy and paste this command:
cd "%USERPROFILE%\Desktop\CLOTHES"

Step 3: Start the App
----------------------
Type this command:
npm run dev

That's it! Your browser will open automatically at:
http://localhost:3000

========================================

⚠️ FIRST TIME SETUP
====================

If you see "npm is not recognized":
→ Node.js is not installed
→ Download from: https://nodejs.org/
→ Install and restart computer
→ Then run the commands above

If you see "cannot find package.json":
→ You're in the wrong folder
→ Run this command:
   cd "%USERPROFILE%\Desktop\CLOTHES"

If you haven't installed dependencies yet:
→ Run this command once:
   npm install
→ Wait 2-3 minutes
→ Then run: npm run dev

========================================

🔧 TROUBLESHOOTING
===================

Navigation links not working?
→ Make sure app is running (see "Quick Start" above)
→ Check URL is http://localhost:3000
→ Press F12 and check Console for errors
→ Try Ctrl + F5 to hard refresh

Can't see navigation menu?
→ On desktop: Make browser window wider (>768px)
→ On mobile: Click menu icon (☰) in top right
→ Try zooming out: Press Ctrl + 0

Links click but nothing happens?
→ Check browser console (F12)
→ Make sure JavaScript is enabled
→ Try different browser
